APPLY
1. Confirm branch/status:
   git branch --show-current
   git status --short --branch

2. Back up or commit any local work first.

3. Copy the contents of this patch into C:\laragon\www\fitcrew, preserving paths and allowing overwrite.

4. Remove the obsolete public directory:
   Remove-Item ".\public" -Recurse -Force

5. Remove the obsolete old design-notes location if present:
   Remove-Item ".\assets\design" -Recurse -Force

6. Ensure Laragon's document root is C:\laragon\www\fitcrew (NOT ...\fitcrew\public).

7. Restart Apache/Laragon so .htaccess rules are active.

8. Run PHP lint and browser/security smoke tests before commit.
